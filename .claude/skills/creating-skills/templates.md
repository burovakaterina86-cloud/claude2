## Простой скилл

Хватает одного файла, если тело короче пары экранов.

````markdown
---
name: writing-commit-messages
description: Составляет сообщения коммитов по git diff в формате type(scope). Применять, когда просят написать сообщение коммита или посмотреть подготовленные изменения.
---

# Сообщения коммитов

1. Посмотри `git diff --staged`.
2. Напиши заголовок `type(scope): суть`, до 72 символов.
3. Если изменений несколько, добавь список через дефис.
````

````markdown
# Обработка PDF

## Быстрый старт

Текст извлекай через pdfplumber (`pip install pdfplumber`):

```python
import pdfplumber
with pdfplumber.open("file.pdf") as pdf:
    text = pdf.pages[0].extract_text()
```

## Дальше

- Заполнение форм: [forms.md](forms.md), читай, когда нужно заполнить форму.

- Примеры: [examples.md](examples.md), читай, когда нужен образец.
````

## Скилл со скриптом

В инструкции всегда указано: запустить или прочитать.

````markdown
## Шаги

```
- [ ] 1. Разобрать форму: запусти analyze_form.py
- [ ] 2. Заполнить fields.json
- [ ] 3. Проверить: запусти validate_fields.py, исправь ошибки, запусти снова
- [ ] 4. Заполнить форму: запусти fill_form.py
- [ ] 5. Проверить результат
```

Запуск: `python3 ${CLAUDE_SKILL_DIR}/scripts/analyze_form.py input.pdf > fields.json`
Установка: `pip install pypdf`
Алгоритм разбора полей читай в `scripts/analyze_form.py` только если скрипт упал.
````

## Хрупкая операция

````markdown
## Миграция

Запусти ровно эту команду:

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/migrate.py --verify --backup
```

Не меняй команду и не добавляй флаги: без `--backup` откат невозможен.
````

## Образец формата результата

Жёсткий формат:

````markdown
ВСЕГДА используй ровно эту структуру:

```markdown
# [Название]
## Резюме
[Один абзац]
## Выводы
- Вывод с данными
## Рекомендации
1. Конкретное действие
```
````

Гибкий формат: «Вот формат по умолчанию, подстрой разделы под анализ».

## Примеры вход - выход

Если качество зависит от стиля, дай 2-3 пары.

````markdown
Вход: Добавил вход по JWT
Выход:
```
feat(auth): вход по JWT

Добавлены эндпоинт входа и проверка токена
```
````

## Ручной скилл

Для действий с побочными эффектами (деплой, рассылка): Claude не должен запускать их сам.

````markdown
---
name: deploying-app
description: Выкатывает приложение на сервер по списку шагов.
disable-model-invocation: true
---
````

Вызывается только `/deploying-app`, описание в контекст не попадает.
